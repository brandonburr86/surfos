env - show the environment, or run a program with a changed one

SYNOPSIS
    env [-i] [name=value]... [program [arg...]]

DESCRIPTION
    With no program, prints the environment, a name=value line each,
    with the assignments put over it. With a program, runs it with the
    environment so made and waits for it. A name without a / is looked
    for in the directories of the new environment's PATH, /initrd/bin
    when it has none.

    The status is the program's, 137 when the kernel killed it and 127
    when there is no such program.

OPTIONS
    -i  Start from an empty environment.

EXAMPLES
    env | sort
    env -i PATH=/initrd/bin env
