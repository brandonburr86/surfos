surfsh - the SurfOS shell

SYNOPSIS
    surfsh [-l]
    surfsh -c text [name [args]]
    surfsh file [args]

DESCRIPTION
    init starts surfsh on every console, and again when it ends. Typed
    at a prompt it starts a shell inside the shell. -c runs text, with
    name as $0, and a file runs its lines without a prompt. Commands as
    in other shells work: quotes, redirections, pipelines, ; && || ! & (
    ) { }, here-documents, variables, $( ), $(( )), wildcards, if,
    while, until, for, case, functions.

    A word finds its command in this order: a special builtin such as
    export, a function, surfsh's other own commands, a program in the
    directories of PATH, then a kernel command. A name with a / is a
    program's path. type says which runs, help lists them, and kernel
    NAME runs the kernel's.

    SurfOS has no fork: every process starts as a new program, so ( )
    and a stage of a pipeline that is surfsh's own run in a new surfsh.
    The last stage is the exception, and runs in this shell: echo a |
    read x; echo $x prints a. A kernel command reads only the console,
    so it can begin a pipeline but not follow a |, and its output
    arrives when it is done. A program gets descriptors 0 to 3.

    At the prompt long output stops at --More--: Space shows the next
    screenful, Enter one more line, and q leaves the rest. The settings
    come from /initrd/etc/surfsh.conf; an interactive shell then runs
    surfos-config/surfshrc from the stick SurfOS started from, if there
    is one.

OPTIONS
    -l       Print the banner, as init starts it.
    -c text  Run the text.

KEYS
    Left, Right  Move. Home, End, ^A and ^E too; ^Left, ^Right, Alt+B
                 and Alt+F by words.
    Up, Down     The lines typed before.
    Backspace    Delete before the cursor; Delete, under it.
                 Alt+Backspace and Alt+D delete a word.
    ^U ^K ^W     Delete the whole line, to its end, or back to the last
                 blank.
    ^R           Search the lines typed before.
    Alt+.        The last word of the line before.
    Tab          Complete; a second Tab lists the choices.
    ^L           Clear the screen.
    ^C           Drop the line, or stop what runs.
    ^Z           Stop the program that runs, as a job.
    ^D           On an empty line, leave this shell.

STATUS
    0    Success.
    1    A failure.
    2    A command used the wrong way.
    126  A program that could not be started.
    127  No such command.
    130  Stopped with Ctrl+C.
    137  Killed.
    141  Its pipe's reader had gone.
    148  Stopped with Ctrl+Z.

EXAMPLES
    surfsh -c 'for i in 1 2; do echo $i; done'
    surfsh /hda1/BACKUP.SH
