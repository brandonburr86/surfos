grep - print the lines that match a pattern

SYNOPSIS
    grep [-ivnclqEF] [-e pattern] pattern [file...]

DESCRIPTION
    grep prints the lines of the files, or of standard input, that the
    pattern matches. With more than one file, each line comes after its
    file's name and a colon. The pattern is a basic regular expression
    (man regex). A [ that is never closed stands for itself.

OPTIONS
    -E          The pattern is an extended regular expression.
    -F          The pattern is a fixed string. Of -E and -F the last one
                counts.
    -e pattern  The pattern, which may then start with a -.
    -i          Ignore the case of A to Z.
    -v          The lines that do not match.
    -n          Each line's number before it.
    -c          How many lines there are, not the lines.
    -l          Only the names of the files that have one.
    -q          Nothing at all: only the status.

STATUS
    0 when a line was found, 1 when none was, 2 for trouble: a mistake
    in the pattern, or a file that cannot be read (with -q, a line found
    counts for more).

EXAMPLES
    grep -n main /hda1/PROG.C
    grep -E '(error|warning): [0-9]+' /hda1/LOG.TXT
    dmesg | grep -i usb
