run - start a program

SYNOPSIS
    run program [args...]
    spawn program [args...]

DESCRIPTION
    run starts a program and waits for it, then says its pid and exit
    status; spawn starts it in the background and returns. A name means
    /initrd/bin/name unless it has a / in it. In surfsh, typing the name
    is the usual way, and & the way to start a job; these two are the
    ring-0 shell's. A surfsh that run starts has no job control.

    run's status is the program's, and 1 when it could not start or was
    killed.

EXAMPLES
    run hello a b
    spawn count 100 100

SEE ALSO
    surfsh, jobs, ps
