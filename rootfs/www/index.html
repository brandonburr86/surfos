Host your own site

  1. On your computer, put the site in a folder named www on a FAT32 USB stick: an index.html, a style.css, pictures.
  2. Plug the stick into the SurfOS machine and mount it: mount usb1p1 /data (lsblk lists the sticks).
  3. Stop this sample and serve your folder: httpd off, then httpd on /data/www.
  4. Open the address it prints in a browser on the same network.

Every folder inside is a site of its own: /data/www/blog/ is at http://…/blog/. A folder without an index.html is listed, so the sites can be found. Edit a page and reload: the files are read fresh every time.

Commands

httpd on [folder] [port]
serve a folder in the background
httpd serve [folder] [port]
the same on one console, every request printed
httpd off
stop the server
httpd
is it running?

What it sends

Pages, style sheets, scripts, pictures (PNG, JPEG, GIF, SVG, WebP), fonts and PDFs, just as they are in the folder. Nothing runs on the server and nothing is uploaded.

Names that start with a dot, such as the ._ files a Mac leaves on a stick, are never shown.
