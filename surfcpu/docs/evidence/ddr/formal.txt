## the checks are not vacuous: they fail on broken designs (same harnesses, mutated RTL)
mailbox prove, mailbox sending while full (src_ready ignored): FAIL
bridge prove, s_rsp_valid not gated by rst: FAIL
bridge prove, watchdog removed (expire = 0): FAIL
bridge prove, calibration failure ignored (cal_done_q <= calib_seen): FAIL
bridge prove, timeout cleared by a refused access: FAIL
bridge prove, a request sent while another is in flight (can_send = rq_ready): FAIL
bridge prove, the in-flight flag reset by rst: FAIL
bridge prove, no answer for a request a controller reset interrupted: PASS (only recovery suffers:
  every later access times out; caught in simulation by watchdog-drop-read)

## the earlier design (4-bit request ids, commit cbabe86)
the 'no stale answer' property did not converge in over an hour of PDR; to 40 steps it passed.
It was in fact false beyond that depth: the wrap test shows the stale answer after 15 resets.
With one request in flight the same property is proved in seconds.
