and the compile does not fit 1,750 MB. So netlist_sim.sh ran as two copies under the worktree's ignored
build/g4-fix/tools/ (the tracked script unchanged): its build half, the same commands up to the Verilator
build, in a big container (both slots, 3,500 MB), and its run half, the same binary run with the same
arguments (+stop=GPUDIAG: +max_ms=3000 +transcript=.../uart.txt) and the same report, in a small one, then
gpudiag_check against the manifest as mk/area-gpu.mk runs it. The copies differ from the script only where
it was cut: the build half writes the build's seconds and stops before the run; the run half keeps the
variables, does not delete the output directory or build, and reads the build's seconds.
