# SurfOS Desktop Implementation Plan

**Goal:** Deliver a usable small SurfOS desktop and verified native mouse input.
**Architecture:** Existing graphics session; pure GUI model/renderer; bounded pointer
queue fed by independent PS/2 and USB transports. Preserve text recovery.
**Tech stack:** Freestanding C, existing font/framebuffer, xHCI, Docker GCC, QEMU/OVMF.
**Spec:** ../specs/2026-10-10-desktop-design.md

## Tasks
- [x] Add `include/sys/pointer.h`, `driver/pointer.c`, host tests: clamping,
  signed relative movement, separate device buttons, unplug and queue overflow.
- [x] Extend `kernel/keyboard.c` for a bounded PS/2 auxiliary probe, IRQ12 and
  polling; pure packet decoder and tests; keep keyboard traffic separate.
- [x] Add `driver/usb/mouse.c` and descriptor/report tests for USB HID boot mice;
  use existing USB lifecycle and interrupt transfers; release buttons on unplug.
- [x] Add pure desktop model/renderer and `shell/gui.c`: menu, two apps, settings,
  moving/closing windows, keyboard controls and explicit temporary sketch state.
- [x] Add host/boot/UEFI integration coverage, build O0/O2 and run required suites.
- [x] Document launch, controls, verified scope, limitations and hardware evidence.

## Review focus
Queue overflow cannot stick buttons; long/broken PS/2 packets cannot type keys;
USB unplug cannot leave DMA writing freed storage; graphics ownership loss stops
input consumption; redraw must not hold off scheduling for full-screen rendering.

## Execution notes
The user's instruction authorizes implementation; proceed with routine design
choices. Driver transports have independent files and a fixed shared contract and
can be implemented in parallel. All integration/Makefile edits belong to the root
worker. Keep unrelated Undertow work intact. Hardware touchpad facts pending.

## Validation receipt (2026-10-12)

The final desktop build passes all host tests, `make test-all` at O0 and O2
(286 smoke checks and 51 Files checks at each level), and all 15 USB/UEFI
scenarios at both levels (307 checks each, including 48 GUI checks). The owner
confirmed the deployed desktop works on the IdeaPad. Its native touchpad does
not work; follow-up is tracked in the 2026-10-12 touchpad plan.
